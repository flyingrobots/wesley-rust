# Changelog

All notable changes to this project are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## Unreleased

### Added

- `crates/wesley-emit-rust`, Wesley's existing emitter, moved from flyingrobots/wesley at `bfff0f9a` (0.3.0-alpha.4) with its history and the fixtures its tests read. It depends on the published `wesley-core` and `wesley-emit-codec` 0.3.0-alpha.4 (flyingrobots/wesley#882).
- The repository, its license, and the rules for how the target generates code (flyingrobots/parley#116, flyingrobots/wesley#882).
- `crates/wesley-rust-syntax` 0.1.0, generic helpers for generating Rust with `syn`, `quote` and `prettyplease`: `naming::{type_name, field_name, variant_name, snake_case}`, `ident` (raw for `r#keyword`), `doc_attrs` and `inner_doc_attrs` (printed as `///` and `//!`), `print_file` (exactly one trailing newline) and `unique_names` (deterministic de-duplication). Its naming functions are `wesley-emit-rust`'s, moved rather than rewritten. Its tests compile a golden model with `rustc` offline against stand-ins for `serde` and `serde_json`, and fail if a string literal under its `src/` holds Rust syntax.

### Changed

- `wesley-emit-rust` takes its names from `wesley-rust-syntax`. Output is unchanged for every fixture; it differs only for names the old helpers got wrong or left non-idiomatic. A field named `self`, `super` or `crate` becomes `self_` (it was `r#self`, which is not a Rust token). Acronyms split as words (`userID` gives `user_id`, was `user_i_d`; `HTTPServer` gives `http_server`). A type name with an interior underscore is PascalCase (`foo_bar` gives `FooBar`, was `Foo_bar`). A variant mixing case and underscores keeps its humps (`camelCase_x` gives `CamelCaseX`, was `CamelcaseX`). Names that GraphQL cannot write (hyphens, a leading digit) follow the new crate's rules. Any renamed field keeps its wire name in `#[serde(rename)]`. Because type names are now PascalCase, `foo_bar` and `FooBar` normalise to the same name; the name table from #5 gives the later one `FooBar2`. The name table now uses `wesley_rust_syntax::unique_names`, the same algorithm, in place of the emitter's private copy.

### Fixed

- A `Float` field's LE-binary codec now compiles against its model (#3). The wire width stays **`f32`**: it is the shared codec plan's contract (`wesley-emit-codec` `ScalarKind::Float`), and flyingrobots/wesley-typescript's codecs write the same four bytes, so changing it here alone would split the two on the wire. The model stays **`f64`**, because GraphQL `Float` is double precision and the serde model must hold any JSON value the schema allows. The codec converts at the boundary, explicitly: the encoder writes `value as f32`, which rounds to the nearest `f32` (ties to even, out-of-range values to infinity), exactly as the TypeScript codec's `writeF32Le(number)` narrows a JavaScript number, and the decoder widens with `f64::from`, which is exact. Encoding is therefore lossy for an `f64` that has no exact `f32`, on both targets alike; a schema that needs full double precision on the wire needs a wider `ScalarKind` in the shared plan, which is a contract change for both targets, not a fix here.
- Recursive types compile (#4). A field or union member that holds a type by value is boxed (`Box<Node>`, `Option<Box<Node>>`, `Variant(Box<Member>)`) exactly when the held type can reach the holder again by value, that is, when both lie in the same strongly connected component of the by-value reference graph; a self reference is the one-type case. List references already have a `Vec` between them and are never boxed, and edges that are not on a cycle are left as they were, so acyclic schemas emit the same bytes as before. The answer depends only on the graph, so it is deterministic. The LE-binary decoders wrap those fields in `Box::new`; the wire is unchanged.
- Names that normalise to the same Rust identifier no longer emit duplicate definitions (#5). The emitter **disambiguates** rather than refusing, because it returns source text and has no error channel. Within each scope (type names, including each operation's request and response; fields of one struct or request; variants of one enum or union; LE-binary codec function names) names are taken in source order: a name keeps its normalised form when that form is free, and a later name whose form is taken gets the first numeric suffix, counting from 2, that is neither taken nor the unsuffixed form of another name in the scope. The suffix is appended directly to a PascalCase name (`Thing2`, `FooBar2`) and after an underscore otherwise (`foo_bar_2`, `type_2` for a second `r#type`). Wire names are unchanged: a renamed field or variant keeps its source name in `#[serde(rename)]`. Models, codecs and law validators read one name table, so they agree. Schemas without collisions emit the same bytes as before.
